# Snapmaker-Orca-Bambu-Filaments
Bambu Lab Filaments &amp; Official Color Palettes for Snapmaker Orca.

Add Bambu Lab PLA Basic and PLA Matte filament profiles to Snapmaker Orca, including their official color palettes.

You can select Bambu filament colors directly from the "Official Filaments" color picker, just like with Snapmaker filaments.

No recompilation or software modifications required!

Tested on Snapmaker Orca 2.4.1 for Windows, but you should be able to replicate also on other versions or operating system. 

NOTE: This is an unofficial community modification. Please back up your existing profiles before installing.

1. CLOSE Snapmaker Orca completely.

2. BACK UP your existing system/Snapmaker folder (C:\Users\<user>\AppData\Roaming\Snapmaker_Orca\system) before making any changes.

3. ENABLE THE FILAMENT PROFILES: Copy the provided Snapmaker.json file into system/Snapmaker, replacing the existing file. This registers the Bambu Lab filament profiles in Snapmaker Orca.

4. INSTALL THE FILAMENT PROFILES AND COLOR PALETTES: Copy the five JSON files from the provided filament folder into system/Snapmaker/filament, replacing existing files when prompted.

5. RESTART Snapmaker Orca.

ENABLE THE NEW FILAMENTS: Open the filament selection menu and, if the new profiles are not already available, go to Add/Remove Filaments and enable Snapmaker Bambu PLA Basic @U1 and Snapmaker Bambu PLA Matte @U1.

SELECT A FILAMENT: Choose Snapmaker Bambu PLA Basic @U1 or Snapmaker Bambu PLA Matte @U1, then click the filament color swatch to access the official Bambu Lab color palette.
